# Task specs (archive)

Per-task specifications, kept for provenance and organized as
`YYYY/MM/<task-id>/`.

**This directory is an archive, not current context.** A task spec describes what
was intended at the time it was written and is never updated afterwards, so it goes
stale by design. Do not treat one as a description of how the system behaves now:
read the owning spec under [../system-specs/](../system-specs/README.md) instead.
