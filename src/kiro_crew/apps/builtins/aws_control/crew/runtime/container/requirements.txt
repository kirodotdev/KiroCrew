# Container runtime only. These must NOT become dependencies of the Kiro Crew app
# itself: the app's backend hooks are imported into the owner's gateway process,
# and adding a web framework to every owner's gateway buys nothing.
#
# No `--hash` entries, deliberately: pip's hash-checking mode is all-or-nothing
# per invocation, and the image's single `pip install` also installs the locally
# built vendor/*.whl, whose hash cannot exist in this file. So these pins bound
# only the DIRECT dependencies; transitive resolution can still drift between
# builds. Full hash pinning would need a compiled lockfile and the vendor wheel
# split into its own unhashed install.
