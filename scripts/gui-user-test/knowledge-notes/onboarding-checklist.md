# Onboarding checklist

A new teammate's first week, in order. Tick each item off as it lands.

## Day one

- Get a laptop and sign the equipment form.
- Join the team chat channel and say hello.
- Read the team glossary so the acronyms in stand-up make sense.

## First week

- Pair with a buddy on one small bug fix end to end.
- Set up the local development environment from the README.
- Attend one release review to see how a change reaches production.

## By the end of the month

- Own one small feature from design note to shipped change.
- Add at least one improvement to this checklist for the next person.
