Three rules from docs/request-for-change/rfc-aws-owner-granted-access.md (PR 3, guards, M10) refuse a command whose output is a credential: aws configure export-credentials, aws configure get of a secret or token key, and ada credentials print. Each is a catalog row matched on argv by a few helpers in argv_rules.py, which also reads kiro-cli's Running: title and a program name in any case or with a Windows suffix. deny_gate.py strips only a shipped-only copy of an argv row's pattern from the regex tier, so an operator's own pattern with the same text keeps working.
