The credential-mint floor binds on a verb (or protected program) that a
substitution names, not on what it would print. Main's resolution is kept exactly
as it is: its binding and its verdict are the baseline. When an assignment's value
is a command substitution, a SECOND (alternative) resolution is also offered, in
which the variable is bound to the program (protected program wins) or verb that
the substitution's OWN body names, read quote-aware from the raw source where that
body's quotes still close (_substitution_bodies with raw_source, _matching_close_backtick
for a backtick body) -- so a lone dequoted quote never arises and a name in a
${...} prefix or a later command is never read as the body's own. The command is
refused if EITHER resolution refuses. That makes monotonicity structural rather
than argued: the baseline frame is kept untouched and the alternative only ADDS a
frame (and descends its nested payloads), so the floor refuses a superset of what
main refuses -- a property test proves the baseline frames are a subset of the
union frames over the whole oracle corpus and every substitution line in the repo.
The double resolution runs only where such an assignment exists. The alternative reads ONE body per assignment with the shared closers, so
many substitution assignments do not make it quadratic. Each assignment
takes its own reading, so a later reassignment of the name is not bound to an
earlier assignment's verb. The alternative reads only the assignments
the baseline binds, and of those only the ones that set a variable in this shell
(prefix position, top level in the raw text): a subshell, argument, nested
substitution or function-body assignment is left unpaired, so main's binding stands. Only refusals
were added. Re-measured.
