The git/tar self-target floor reads the path of a tar archive or scp-like git remote word, after a plain host, the way the ssh floor reads an scp file operand, so shell arithmetic in a remote file name (backup.example.com:backup-$((1+1)).tar) no longer refuses a remote host. The narrower read applies only when the host part holds no $, backtick or [ and the path holds no @, backtick or expansion other than $((, and for git only to a word git itself reads as a remote (a keyword on _git_remote_targets_self that defaults to the strict read, set at the argv, remote-URL config and insteadOf sites); a word of a carried command value keeps the strict read. Nothing allowed before is refused now.
