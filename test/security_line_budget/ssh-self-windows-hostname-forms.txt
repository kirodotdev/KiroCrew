The ssh-to-self floor's run-time spellings of this host's own name gain the Windows ones, PowerShell's $env:COMPUTERNAME (bare and braced) and cmd's %COMPUTERNAME%, in a helper that reads them where an ssh operand names a host: whole, after user@ (and after the last @ when userinfo holds a colon), as a ssh:// URI authority, before a path colon, or dotted in host position. An scp/rsync file operand or a tar remote word with no host colon (the $env: colon is not one) is a local path, and its host ends at the first colon; a file_operand flag passed through the operand recursion marks it. A git remote word, which may also be a refspec or a remote name, counts a Windows name only in clear transport syntax (a URL authority or scp-like user@host:path), through a context variable like _LITERAL_HOSTS set by _git_remote_targets_self around its body. The argv_floor facade names the new helpers. Adds refusals only for the Windows spellings; nothing refused before is allowed now.
