The ssh-to-self floor's run-time spellings of this host's own name gain the Windows ones, PowerShell's $env:COMPUTERNAME (bare and braced) and cmd's %COMPUTERNAME%, in a helper that reads them where an ssh operand names a host: whole, after user@ (and after the last @ when userinfo holds a colon), as a ssh:// URI authority, before a path colon, or dotted in host position. An scp/rsync file operand or a git/tar remote word with no host colon (the $env: colon is not one) is a local path or a name, and its host ends at the first colon; a file_operand flag passed through the operand recursion marks it. A git push refspec word is read without the Windows spellings, through a context variable like _LITERAL_HOSTS, since a refspec names refs; the refspec positions come from a split in argv_floor_git that reuses the push floor's own option arity tables and returns none on an option they do not model. The argv_floor facade names the new helpers. Adds refusals only for the Windows spellings; nothing refused before is allowed now.
